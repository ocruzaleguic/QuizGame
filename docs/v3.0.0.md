🐞 2. CORRECCIÓN DE ERRORES:

    2.1. Fallo al iniciar sesión
    
        > Error:

            Al momento de cerrar sesión, no permitía volver a ingresar a tu usuario. Solamente funcionaba para los usuarios semilla
        
        > Motivo:

            La contraseña del usuario se sobrescribía al sincronizar loggedUser en registeredUsers

        > Solución:

            Evitar usar loggedUser para persistencia y preservar siempre el campo password en syncUser(). loggedUser solo se usa para saber qué usuario está logeado.
